# Точка Кофе — Сайт и QR-меню (React + Vite + Tailwind CSS)

Готовый проект для публикации на бесплатном хостинге **Vercel**.

## Как выложить на Vercel за 2 минуты (без консоли и установки программ)

1. Распакуйте этот ZIP-архив.
2. Зайдите на https://github.com и создайте новый пустой репозиторий (например, `tochka-kofe`).
3. На странице пустого репозитория нажмите ссылку **uploading an existing file**.
4. Откройте распакованную папку `tochka-kofe` и перетащите в окно браузера **всё её содержимое** (`index.html`, `package.json`, `vite.config.js`, `tailwind.config.js`, `postcss.config.js`, `vercel.json` и папку `src`).
   > Важно: файл `package.json` должен оказаться прямо в корне репозитория, а не внутри лишней папки.
5. Нажмите зелёную кнопку **Commit changes**.
6. Зайдите на https://vercel.com через GitHub → **Add New… → Project** → выберите репозиторий `tochka-kofe` → нажмите **Deploy**.

Через 30–60 секунд Vercel выдаст готовую чистую ссылку вида `https://tochka-kofe.vercel.app`.

## Если хочется запустить локально на ПК

```bash
npm install
npm run dev
```
